Điều gì xảy ra tiếp theo?

CreditLens tiếp nhận dữ kiện, tính toán bằng mã xác định, đối chiếu bằng chứng và trình bày kết quả để chuyên viên xem xét. Giao diện không tự đưa ra quyết định tín dụng.
